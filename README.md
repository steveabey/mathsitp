# ITP Studio

Interactive maths teaching programs for the classroom board.

- `public/` is the live website. Cloudflare deploys it every time this repository changes.
- `source/` holds the source files used to build `public/index.html`.

## Updating the site
Replace the files in `public/` with the new ones (for example by dragging them onto the
`public` folder on GitHub and committing). Cloudflare picks up the change and deploys it
within a minute or two. Check the progress under the Worker's Deployments tab.
